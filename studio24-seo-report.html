Key Findings
Studio 24 has a highly premium aesthetic and strong brand messaging rooted in the "Company DNA", but its technical foundation severely restricts search visibility. Across all 4 primary pages, there are exactly zero <h1> tags, removing Google's primary method for determining page topics. Furthermore, 100% of the pages share the exact same meta title and description inherited from the global Next.js layout, causing total keyword cannibalization. Finally, the site entirely lacks crucial LocalBusiness and HairSalon structured data markup, which is vital for dominating local map-pack searches in Frederiksberg for core services like Balayage and Extensions.

Duplicate Content & Cannibalization

100% Metadata Duplication

Because metadata is only defined in app/layout.tsx, all pages currently share the exact same Title and Meta Description. This causes Google to filter out the subpages as "duplicates" and severely damages ranking potential for specific services.

Move unique metadata into each individual page.tsx route. Keep layout.tsx as a fallback only.
Critical
Robots.txt & Sitemap

Missing Sitemap & Robots.txt

There are no sitemap.xml or robots.txt files at the root of the project. These are essential for instructing Google's crawlers on how to navigate the site.

Create app/sitemap.ts and app/robots.ts using Next.js built-in API to generate these dynamically.
